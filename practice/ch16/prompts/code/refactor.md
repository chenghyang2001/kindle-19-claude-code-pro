# 重構（不改變功能）

## 用途
程式能動但難讀、重複、巢狀太深時，讓 Claude 改善品質，同時保證行為不變。

## 變數
| 變數 | 說明 | 範例 |
| --- | --- | --- |
| `{{language}}` | 程式語言 | Python |
| `{{goals}}` | 重構目標 | 可讀性、移除重複 |
| `{{constraints}}` | 不能動的東西 | 函式簽名、回傳值格式 |
| `{{code}}` | 原始程式碼 | （貼上程式碼） |

## 模板
---
你是一位 {{language}} 重構專家。請重構下面的程式碼。

目標：{{goals}}
限制（絕對不能改）：{{constraints}}

規則：
1. 外部可觀察行為必須完全相同（相同輸入 → 相同輸出 / 相同例外）。
2. 一次只做一種重構手法，並說明使用的手法名稱（例如 Extract Function、Replace Loop with Pipeline）。
3. 若發現既有 bug，不要順手修，改列在最後的「發現的問題」。

原始程式碼：
```
{{code}}
```

輸出格式：
- 重構後完整程式碼（一個程式碼區塊）
- 變更清單表格（手法 / 位置 / 理由）
- 發現的問題（沒有就寫「無」）
---

## 範例填入
- language = `Python`
- goals = `可讀性、改用內建函式`
- constraints = `函式名稱與參數、回傳 round(..., 2)`
- code = `samples/order_utils.py` 的 `calc_total`

## 預期輸出格式
重構後程式碼 + 變更清單表格 + 發現的問題（應指出 `average_price` 空清單問題或 discount 範圍未檢查）。

## 使用說明
重構前先跑一次「寫測試」模板產生測試，重構後用同一組測試確認行為不變。
