# 解釋程式碼（依對象調整）

## 用途
要把一段程式碼講給不同背景的人聽（新人、PM、主管、自己半年後），讓 Claude 依對象調整深度與用詞。

## 變數
| 變數 | 說明 | 範例 |
| --- | --- | --- |
| `{{audience}}` | 聽眾是誰、懂多少 | 不寫程式的產品經理 |
| `{{purpose}}` | 他們想知道什麼 | 折扣怎麼算、會不會算錯 |
| `{{length}}` | 長度限制 | 200 字以內 |
| `{{code}}` | 程式碼 | （貼上程式碼） |

## 模板
---
請把下面的程式碼解釋給「{{audience}}」聽。
他們最想知道：{{purpose}}

規則：
1. 用對方熟悉的詞彙；出現專有名詞時用一句話白話解釋。
2. 先講「這段在做什麼」，再講「怎麼做」，最後講「要注意什麼」。
3. 至少舉一個具體數字的例子走一遍流程。
4. 長度：{{length}}。

程式碼：
```
{{code}}
```

輸出格式：三個小標題「做什麼 / 怎麼做（含例子）/ 注意事項」。
---

## 範例填入
- audience = `不寫程式的產品經理`
- purpose = `折扣怎麼算、金額會不會算錯`
- length = `250 字以內`
- code = `samples/order_utils.py` 的 `calc_total`

## 預期輸出格式
```
### 做什麼
### 怎麼做（含例子）
### 注意事項
```

## 使用說明
同一段程式碼換不同 `audience`（新人工程師 / 主管）各跑一次，比較用詞差異，很適合拿來練習 prompt。
