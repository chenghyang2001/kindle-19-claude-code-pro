## 和題目要求的差異

| 題目要求 | 實際做法 | 原因 |
|---|---|---|
| 至少 5 個異味 | 找了 14 個 | 多找的包含死碼、旗標參數、回傳型別不一致等較隱晦的問題 |
| 至少 4 個測試 | 重構前 12 個，最終 16 個 | 額外鎖住 `r == True`、int 0、未知類型等容易被重構改壞的怪行為 |
| 只做 Rename + Extract | 另外順手做了「魔術數字→具名常數」「if/elif→字典分派」「手寫迴圈→`sum()`」 | 屬於 Extract 時自然發生的整理；行為已用等價比對確認不變。嚴格「一次一個手法」的話，這些應該拆成獨立 commit |
| 重構 = 不改行為 | 刻意保留 `return_average == True`、空結果回 int `0`、未知類型不檢查 | 這些是怪行為，但修正屬於「改行為」，在 ex02 延伸思考列為下一步，未在本練習執行 |
| 每步驟「提交（或記錄）」 | 每步驟都有獨立 git commit + log 檔 | — |
| — | 保留 `process = clean_sensor_readings` 別名 | 避免舊呼叫端一次全壞（題目未要求） |
