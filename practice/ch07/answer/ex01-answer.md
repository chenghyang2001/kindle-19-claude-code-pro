# 練習 01 解答：識別程式碼異味

## 任務 1：異味掃描（共 14 項）

| # | 異味類型 | 具體問題 | 影響程度 |
| --- | --------- | --------- | :---: |
| 1 | 命名含糊 | 函式名 `process` 沒說明做什麼（其實是「過濾感測值並算平均」） | 高 |
| 2 | 命名含糊 | 參數 `d`、`t`、`r` 單字母，呼叫端 `process(x, "pm25", False)` 完全看不懂 `False` 是什麼 | 高 |
| 3 | 巢狀太深 | `if d → for → if != None → if t → if 範圍 → if != 998` 共 6 層，閱讀要記住整條路徑 | 高 |
| 4 | 一個函式做太多事 | 同時負責：去 None、依類型過濾、計算平均、決定回傳型態 | 高 |
| 5 | 旗標參數（Flag Argument） | `r` 讓同一個函式回傳兩種不同型態（float 或 list），呼叫端得自己記住 | 高 |
| 6 | 死碼（Dead Code） | `d[i] != 998` 永遠為真：能走到這裡的值已經 ≤ 500，998 早就被範圍條件擋掉。**已用變異測試證實**：刪掉此條件測試全綠 | 中 |
| 7 | 無意義分支 | 兩個 `else: pass` 什麼都沒做，只增加行數 | 低 |
| 8 | 魔術數字 | `0`、`500`、`998`、`-40`、`85` 沒有名字，看不出 998 是「感測器故障碼」 | 中 |
| 9 | 非慣用寫法 | `for i in range(len(d))` + `d[i]` 重複 6 次；應直接 `for value in readings` | 中 |
| 10 | 非慣用寫法 | `!= None` 應為 `is not None`；`r == True` 會讓 `r="yes"` 走「回傳清單」分支，行為出乎意料 | 中 |
| 11 | 重造輪子 | 手寫 `total = total + x` 迴圈，應用 `sum()` | 低 |
| 12 | 回傳型別不一致 | 有資料時回 float、沒資料時回 int `0`；無法區分「平均真的是 0」和「沒有有效資料」 | 中 |
| 13 | 缺乏擴充性（Switch 異味） | 新增感測類型（濕度）要再插一層 `elif`；未知類型則靜默不過濾，打錯字 `"pm2.5"` 不會報錯 | 中 |
| 14 | 沒有文件 / 測試 | 沒有 docstring，也沒有任何測試，所以「沒人敢碰」 | 高 |

## 任務 2：優先排序

依「重構後獲益」排序：

1. **#14 沒有測試**（先做）→ 不是重構手法，但它是所有重構的前提。沒有測試網，下面任何一項都可能悄悄改壞行為。
2. **#1、#2 命名**→ 成本最低、獲益最大：改完後每個呼叫點立刻變得可讀。
3. **#3、#4 巢狀＋職責過多**→ 用 Extract Function 拆成 `filter_pm25` / `filter_temperature` / `average`，巢狀自然消失。
4. **#8 魔術數字、#6 死碼、#7 else pass**→ 拆完函式時順手清。
5. **#5 旗標參數、#12 回傳型別不一致、#13 未知類型靜默通過**→ 屬於「改變 API 行為」，要先和呼叫端協調，放最後。

### 1. 最值得先做的是哪個？為什麼？

**命名（#1、#2）**，前提是先補測試網。理由：改名是零邏輯變動、獲益卻遍及所有呼叫點；而且改完名之後，後續拆函式時的討論才有共同語言（「`filter_pm25` 那段」比「第 3 層 if 那段」清楚得多）。

### 2. 哪個最簡單可以快速解決？

**#7 刪掉 `else: pass`** 和 **#11 用 `sum()`**：純機械操作、一行一個、不可能改變行為。

### 3. 哪個最危險（動錯了最容易引入 bug）？

**#10 的 `r == True` 和 #12 的回傳型別**。看起來「順手改成 `if r:`」或「回傳 `0.0` 比較一致」很自然，但會改變行為：

- `if r:` 會讓 `r="yes"` 從「回傳清單」變成「回傳平均」；
- `0` 改 `0.0` 會讓呼叫端用 `is 0` 或型別判斷的程式出錯。

其次是 **#6 死碼**：刪掉 `!= 998` 雖然現在安全，但如果日後有人把上限從 500 調到 1000，998 就會被算進平均——所以重構時我保留成具名常數 `PM25_SENSOR_ERROR`，而不是直接刪除。

這幾點都已寫進練習 02 的特性化測試（`test_r_uses_equality_with_true`、`test_all_filtered_out_returns_int_zero`），變異測試也證實改成 truthy 或 `0.0` 會被測試抓到。
